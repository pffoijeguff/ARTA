# Security Policy

## Current status

ARTA is in the specification/foundation stage. This repository does not yet contain a working application runtime, and the presence of a security specification does not mean the proposed controls have been implemented or independently assessed.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting feature for this repository, if it is enabled. If private reporting is unavailable, contact the repository maintainer privately through a channel listed on their GitHub profile before sharing sensitive details.

Do not include API keys, access tokens, cookies, private user data, or weaponized exploit details in a public issue.

## Helpful report details

Include the affected path or component, the security boundary involved, the impact you observed, minimal reproducible steps, and any safe logs or screenshots with secrets and personal information removed.

## Response expectations

Reports will be assessed according to severity, reproducibility, and project status. No fixed response time or supported-release guarantee is currently promised.
